# Escritório Fedrizzi

Repositório central de projetos do Escritório de Contabilidade Fedrizzi.

## O que fica aqui

- Scripts e automações criados com Claude Code
- Ferramentas de gestão e relatórios
- Qualquer projeto desenvolvido para o escritório

## Como usar

Este repositório é o backup completo de todos os projetos.
Em caso de formatação ou troca de máquina, basta clonar:

```bash
git clone git@github.com:mauriciofedrizzi/escritorio-fedrizzi.git
```
