# Marca Fedrizzi Contabilidade

Logo vetorizado a partir do PDF original (`logo_fedrizzi_contabilidade.pdf`, out/2025).
O símbolo foi redesenhado com geometria exata (faixa de 45°); o texto foi vetorizado do original.
Os SVG escalam sem perder qualidade; os PNG (2000 px, fundo transparente) são para uso rápido.

| Arquivo | Quando usar |
|---|---|
| `logo-fedrizzi.svg` | Fundo branco ou claro (versão principal) |
| `logo-fedrizzi-fundo-escuro.svg` | Fundo cinza-escuro ou preto |
| `logo-fedrizzi-branco.svg` | Fundo turquesa ou petróleo (tudo branco) |
| `simbolo-fedrizzi.svg` | Só o símbolo (avatar, marca d'água, rodapé de post) |
| `simbolo-fedrizzi-branco.svg` | Só o símbolo, branco, sobre fundo colorido |
| `folha-variacoes.png` | Prévia de todas as versões |
